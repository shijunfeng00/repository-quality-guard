# Repository Quality Guard Rules

每个规则独立定义：**检查什么、应该怎么修改、不应该怎么修改**。按编号检索，不按规则族合并。静态证据不足标记 `UNKNOWN`，不得当作安全或错误。

查询入口：`python scripts/quality_guard.py evidence --rule QG003`；源码上下游、变量赋值及调用位置见 [ARCHITECTURE.md](ARCHITECTURE.md)，Case 协议见 [TEST.md](TEST.md)，验收见 [AUDIT.md](AUDIT.md)。

## 完整规则索引

| 规则 | 检查什么（含适用边界） | 应该怎么修改 | 不应该怎么修改 |
| --- | --- | --- | --- |
| `QG000` | Python 语法解析失败；当前文件无法继续做可靠 AST 审查。 | 修复源文件语法错误，使解析器可形成完整 AST | 不得将未解析文件当作零问题 |
| `QG001` | 短小且低复用的内部函数/方法才进入 ephemeral-helper 审查；direct call、callable reference、callback/protocol hook、公开/导出接口都会作为正向复用证据。 | 核对引用与调用，确实仅为一次性且无独立职责才内联 | 不可按行数删除 callback、协议方法或复用 primitive |
| `QG002` | 短小且静态实例化/引用很少的类，检查是否为低价值包装。 | 核实实例职责，纯粹包装类才归并到已有 owner | 不可删除承载实体不变量的领域类型 |
| `QG003` | 经可靠 owner/类型证据证明的内部 Mapping 必读字段使用 `.get(key)` 猜缺失，或无 key 调用；合法可选字段必须有可达生产者及消费路径。未知 owner 转 QG026；Guard 或真实外部可选协议不误报。 | 追溯内部 Mapping 的生产者与必需键合同，必需键直接访问 | 不可将 `.get` 换成 membership/异常兜底掩盖缺字段 |
| `QG004` | 内部正式映射 `.get(key, default)` 的默认值掩盖必需字段缺失；合法 Optional 必须从真实生产路径证明缺失可达、消费方有不同处理，证据不足标 UNKNOWN。 | 证实默认值为可达的合法业务缺失，否则修复生产者并显式报错 | 不可凭 `Optional` 或有默认值就认为兜底正确 |
| `QG005` | `hasattr()` 探测 `internal_formal` 对象仍属于运行时形状猜测；解析到的外部协议字段/动态边界降为所有权证据，unknown 不硬猜。显式 Protocol/ABC/联合类型/override 不属于本规则目标。 | 为正式内部对象使用声明的属性/类型合同 | 不可将 `hasattr` 包成另一个探测 helper |
| `QG006` | `getattr(..., default)` 对 `internal_formal` 对象继续严格；外部可选协议/动态边界只记录低严重度证据，unknown 进入语义复核。不得把内部 formal contract 伪装成外部 optional。 | 在唯一外部适配边界归一化，内部按明确属性访问 | 不可给 formal 对象继续叠 `getattr(..., default)` |
| `QG007` | 宽异常捕获或异常处理器静默吞错；明确终止、可观察诊断或可证实的合法降级可区别处理，不能凭某个日志函数名豁免。 | 对意外错误保留抛出/终止或可信日志，对合法降级显式诊断 | 不可 `except: pass` 或写入无人消费的局部变量 |
| `QG008` | 类直接 authored methods `<=20` 不因数量告警；`21..50` 进入 owner-cohesion Semantic Review；`>50` 才按 Critical。禁止为压方法数制造 wrapper/mixin/helper 碎片。 | 核实类职责，按真实状态与生命周期重新划定 owner | 不可为了降低方法数量机械拆 mixin/helper |
| `QG009` | 通过 `ImportError/ModuleNotFoundError` 选择备用实现或兼容导入。 | 明确唯一受支持依赖及安装契约，必要时将兼容选择放在适配边界 | 不可在生产业务流程以导入失败偷偷切换实现 |
| `QG010` | 经绑定调用图证明没有独立职责的纯转发函数层；具有生命周期、作用域、回调、递归状态初始化等真实职责的入口不算纯冗余，缺边保持 UNKNOWN。 | 确认 caller→wrapper→callee 等价后删除纯转发层 | 不可删掉拥有回调、事务或初始化职责的入口 |
| `QG012` | 稳定映射使用 `setdefault()` 同时读取、兜底和写入。不得机械展开为 `if key not in mapping: mapping[key] = default`；`setdefault(...).add/append/extend/update` 是明确的聚合原语，不命中本规则。其他合法缓存/聚合应保留简洁语义或收拢到唯一状态入口，必需字段则直接索引。 | 聚合容器保留合法聚合原语；正式必需字段直接索引 | 不可把 `setdefault` 机械改写为等价的 `if not in` 兜底 |
| `QG013` | owner 内 `private/internal + tiny + low-reuse` ephemeral helper 达到数量/密度阈值时进入 Semantic Review；共享 primitive、callback/protocol hook、公开接口不计入碎片化。 | 沿 owner 调用图减少无复用、无职责的碎片 helper | 不可将真实共享 primitive 或协议入口合并掉 |
| `QG014` | 单个函数超过配置阈值，属于函数职责臃肿；按 Critical，且不得机械拆成碎片 helper。 | 提炼独立业务职责或收敛重复逻辑以降低函数复杂度 | 不可靠拆一堆一次性 helper 凑行数 |
| `QG015` | 函数参数总数过多，可能混合多项职责。 | 按职责拆分入口或用已有明确类型表达真正相关的参数 | 不可新增无语义参数袋/`**kwargs` 隐藏参数数目 |
| `QG016` | 控制流嵌套层级过深。 | 以早返回、明确状态或职责分离降低真正控制流嵌套 | 不可仅将分支搬进纯转发函数 |
| `QG017` | 默认达到 25 个分支时输出 INFO 语义建议；不因为分支计数直接阻断。 | 审查分支是否有重复语义，能合并才合并 | 不可将 INFO 分支计数当作必删业务分支 |
| `QG018` | 函数接收多个布尔开关，形成隐式模式矩阵。 | 拆开不同业务模式或使用明确类型/枚举契约 | 不可继续累加 bool 标志或隐藏在 dict 中 |
| `QG019` | 模块超出物理行数阈值：1001–2000 行需语义审查，超过 2000 行为 Critical；先核实职责与冗余，不靠机械拆文件消除计数。 | 按独立 owner 与职责拆模块，保留对外接口 | 不可机械切文件或搬进 `utils` 以规避行数 |
| `QG020` | 源码包含静态检查抑制标记，需要确认其必要性和范围。 | 逐个确认抑制范围、原因和必要性，能修实际问题就移除抑制 | 不可扩大 ignore 范围、全局关闭检查 |
| `QG021` | 两个函数具有完全相同的 AST 函数体，属于高置信重复实现；按 Critical。 | 确认等价调用合同后收敛到一个权威实现 | 不可凭相同 AST 合并语义不同的入口 |
| `QG022` | 仓库模块间形成循环依赖强连通分量。 | 找出依赖方向，抽出明确契约或反转依赖打破环 | 不可通过动态导入隐藏依赖环 |
| `QG023` | 捕获 `AttributeError/KeyError/TypeError` 后返回默认结果，掩盖契约错误。 | 恢复精确异常/错误合同，非法内部输入应暴露 | 不可捕获 KeyError/TypeError 后返回空值伪装成功 |
| `QG024` | 使用 `contextlib.suppress()` 完全隐藏异常。 | 让异常可观察或在合法忽略路径记明边界与证据 | 不可用 `suppress` 掩盖内部错误 |
| `QG025` | 稳定映射 `pop(key, default)` 静默忽略本应存在的字段；生产代码按 Critical。 | 必需字段移除时使用正式存在性合同；合法缺失显式分支 | 不可继续 `pop(key, default)` 默默吞缺失 |
| `QG026` | 接收者类型无法确认的 `.get()` 候选，需要核对是否为内部映射契约。 | 先识别调用者和 Mapping owner，能确定必需契约才归入 QG003 | 不可把未知类型一律判成错误或安全 |
| `QG027` | 生产定义缺 docstring；认证的抽象方法覆写且父类有完整合同可继承说明，property 文档按专门规则处理，不能凭同名父方法猜测。 | 给生产定义补上解释职责的 docstring，认证继承例外不重复 | 不可填无信息模板或要求测试代码机械补充 |
| `QG028` | 公开接口 docstring 过短；生产代码单项按 Error 处理。property 类接口由 QG180 的必要性与同步字段审查，不强制机械扩写 Args/Returns。 | 让公开 API 文档准确陈述作用及必要边界 | 不可机械加废话凑字符或强迫 property 增加 Args |
| `QG029` | 公开接口 `Args:` 未覆盖全部非 `self/cls` 参数；生产代码单项按 Error 处理。 | 准确列出公开 API 的实际参数语义 | 不可写与签名不符或遗漏的 Args |
| `QG030` | 公开接口缺少 `Returns:` 或 `Yields:` 说明；生产代码单项按 Error 处理。property 类接口不重复命中。 | 说明实际返回/迭代结果及语义 | 不可编造与真实返回不符的 Returns/Yields |
| `QG031` | 布尔参数使用 `0/1` 或文本布尔作为默认值。 | 使用真正布尔字面量默认值 | 不可让 `0`、`1`、字符串承担布尔合同 |
| `QG032` | 布尔参数类型同时允许 `str/int` 等外部表示。 | 边界只解析一次输入表示，内部参数用明确 bool | 不可把 `str/int/bool` 多类型常态化到内部接口 |
| `QG033` | 内部函数再次解析、比较或 `bool()` 转换多种布尔表示；`bool(set[str])` 是集合非空判断，不能仅凭语法当成布尔文本解析。 | 边界转换合法外部布尔值后传递 bool | 不可将 `bool(set)` 这类集合判空误当布尔文本解析 |
| `QG034` | 函数签名使用 bare `*` 或 `*args`：前者引入额外 keyword-only 调用契约，后者接受未逐项声明的可变位置参数。项目默认优先固定显式参数；参数总量由 QG015 独立检查。 | 显式列出确定参数，确有 keyword-only 业务合同再保留 bare `*` | 不可用不透明 `*args` 逃避签名约束 |
| `QG039` | 参数使用 list/dict/set 可变默认值。 | 改用每次调用独立新建的容器 | 不可让不同调用共享可变默认实例 |
| `QG040` | 参数默认值为 `None`，但类型标注未声明可空。 | 让默认 None 与 Optional/联合类型严格一致 | 不可在不允许空值的类型注解下静默传 None |
| `QG041` | 同名函数参数的旧启发式匹配已停用；只有编译器认证的调用目标与参数绑定才可支持诊断。 | 此旧启发式已停用；需要判断时使用认证的符号绑定 | 不可凭参数同名产生 Finding |
| `QG042` | 使用开放 `**kwargs`，或虽声明有限 key 但在当前函数中读取/改写而非纯透明透传。仅机器可验证的有限契约（优先 `Unpack[TypedDict]`；兼容场景可用 `# RQG-KWARGS: keys=...; mode=forward-only`）且实际只原样 `**kwargs` 透传时不报告。 | 尽量写明固定参数；合法纯转发需认证有限 kwargs 合同 | 不可把未知 key 的读取/修改伪装透明透传 |
| `QG045` | 同一函数返回互不兼容的顶层类型。 | 建立唯一明确返回形态或 discriminated union | 不可一条路径返回 dict 另一条路径返回裸字符串 |
| `QG046` | 非可空返回契约存在隐式落到函数末尾返回 `None` 的路径。 | 确保每条可达路径返回契约类型或显式抛错 | 不可把隐式 None 当默认成功结果 |
| `QG047` | 协议语义函数以 `str/repr` 代替稳定结构化返回。 | 返回稳定的数据结构，并由展示层负责渲染 | 不可用 `repr` 字符串承载机器协议 |
| `QG048` | 捕获异常、记录后继续执行，可能把失败伪装成成功。 | 在日志后显式传播失败或返回正式失败状态 | 不可吞异常继续生成成功输出 |
| `QG049` | 翻译异常时未使用 `raise ... from ...`，丢失异常 cause。 | 翻译异常时使用 `raise ... from ...` 保留因果 | 不可无因由替换异常并丢失根因 |
| `QG051` | 使用 `global/nonlocal` 修改共享状态或闭包状态。 | 给共享状态设置单一 owner 和显式传递方式 | 不可依赖随处 `global/nonlocal` 修改上下文 |
| `QG052` | 生产代码直接使用 `print()`。 | 用正式日志或明确 CLI 输出入口 | 不可在生产库函数里散落 `print()` |
| `QG053` | `subprocess.run()` 未显式检查返回码。 | 根据契约启用 check 或显式核验进程退出码 | 不可忽视失败的 subprocess 返回值 |
| `QG054` | 网络调用未设置明确 `timeout`。 | 为网络访问设置与业务 SLA 相符的明确超时 | 不可无限等待或用超大 timeout 藏死锁 |
| `QG055` | 异步函数直接调用同步阻塞 API。 | 用异步客户端或隔离阻塞操作到线程执行器 | 不可在事件循环直接做同步长阻塞 IO |
| `QG056` | 使用 `eval/exec/compile` 动态执行 Python。 | 替换为静态 dispatch、解析器或已认证表达式求值合同 | 不可执行不受信代码或将 eval 包进 wrapper |
| `QG057` | 按目标名称推断契约对象的旧启发式检测已停用；应使用类型及所有权来源证据。 | 此按名字猜测 owner 的旧规则已停用，改用类型/绑定证据 | 不可通过重命名满足不存在的检查 |
| `QG060` | 类型判别与声明契约：经可靠类型来源证明封闭内置类型不相容才报 CRITICAL；类型关系未知和重复检测不能证明质量缺陷，不因缺少来源证明制造 WARNING。已证明的基类→子类分派不报；具有明确 ABC 所有权、失败即抛 `TypeError`、成功后注册类或调用所声明抽象接口的注册边界不报，不能仅凭函数名或 `raise TypeError` 豁免普通 Consumer。不以 `isinstance()` 语法本身证明缺陷。证据包括类型注解、判别类型、绑定来源及证明分类。 | 核实正式类型来源，必要时用 Protocol/判别式分派 | 不可见 `isinstance` 就认定为错误 |
| `QG061` | 消费方把标量/序列互相包装修复，例如 `x if list else [x]`。 | 修复数据生产者，统一声明的标量或序列协议 | 不可在每个消费者用 `x if list else [x]` 修形状 |
| `QG062` | `zip()` 未使用严格等长语义，可能静默截断。 | 若要求等长，使用 `zip(strict=True)` 或等价显式校验 | 不可静默截断有意义的输入 |
| `QG063` | 通过 `min(len(...))`、切片等方式静默修复长度不一致。 | 确保来源长度符合合同并显式处理不一致 | 不可取最短长度或切片隐藏数据丢失 |
| `QG064` | 同时读取多个字段别名，例如 `id/doc_id` 兼容链。 | 在唯一适配边界统一字段名称 | 不可让消费者长期支持 `id/doc_id` 链 |
| `QG065` | 同一数据同时按对象属性和映射下标消费。 | 确定接口到底是对象还是 Mapping，并让消费者一致 | 不可在同一 owner 混用属性和下标探测 |
| `QG066` | 仅对经未遮蔽内置 `dict` 注解确认为必需、没有缺省值且未重绑定的形参，发现 `argument or {}` 无条件吞并非法 `None` 输入时报高置信 WARNING；真实 Optional、无类型契约或对象属性暂保留 UNKNOWN，不凭名字猜测。 | 核实是否真为必需 dict，必需则拒绝 None | 不可使用 `argument or {}` 吞掉非法输入 |
| `QG069` | 使用 `assert` 承担运行时输入或契约校验。 | 使用正式验证并抛明确异常 | 不可依赖可能被 `-O` 移除的 assert 检查输入 |
| `QG070` | 调用字符串、Path 等不可变对象方法后丢弃返回值。 | 保存或使用不可变对象方法的新返回值 | 不可丢弃替换操作的结果并声称原值已改 |
| `QG080` | 类只有一个公开方法，可能只是函数包装。 | 确认单公开方法类是否维护独立状态/协议，再决定保留或收敛 | 不可把每个类都当函数包装随意删除 |
| `QG081` | 类的私有 helper 数量相对公开方法过多。 | 检查私有方法是否确为 owner 必需职责并收敛一次性 helper | 不可单纯把私有方法改成 public 降比例 |
| `QG082` | 类的大部分方法是 `staticmethod/classmethod`，可能只是命名空间。 | 若仅用于命名空间，复用明确模块/owner；有真实类型协议则保留 | 不可因 classmethod 多就移除领域构造器 |
| `QG083` | 大量实例方法不使用实例状态。 | 核实状态使用及协议，再迁移确实无状态的方法 | 不可随手把方法变 staticmethod 隐藏设计问题 |
| `QG084` | dataclass 只有一个字段，可能重复包装已有值。 | 确认单字段 dataclass 是否有值类型不变量，否则复用既有类型 | 不可删除确有序列化或强类型语义的值对象 |
| `QG085` | 属性或方法只转发内部对象成员。 | 只对不承载不变量/适配契约的透明成员代理去层 | 不可删除必要属性边界或仅改成另一个 delegate |
| `QG086` | 构造函数依赖数量过多或机械保存过多参数。 | 识别职责过多及依赖所有权，按真实边界拆分 | 不可用 `**kwargs` 或参数袋掩饰过多依赖 |
| `QG087` | 构造字段只被极少方法使用，类职责可能可局部收窄。 | 检查字段生命周期和消费者，移走非本 owner 的依赖 | 不可为消除告警机械复制字段到子类 |
